# 更新日志（LIVE直播源）

版本号规则：`主.次.修订`。次版本号用于一批功能性改进，修订号只给单独的小修。外观类微调不单独占版本号。

## v1.3.0（2026-10-19）

**数据源（这是本次改动最大的部分）**

- 新增 4 个经实测可用的源：CCSH·平台源、CCSH·全量源、ChinaIPTV·自动更新、Guovin·IPTV-API。
- 默认关闭 4 个实测不可达的源：kelvin、epg.pw 的香港/台湾/澳门三源（本机到 `stream1.freetv.fun` 全部超时，2026-10-19 实测 0/135 可播）。
- 老配置自动升级（`cfg_ver=2`）：只关闭这 4 个，不覆盖用户其它选择，日志里会写明改了哪些。
- 每轮抓取后对每个源**抽样 20 条**实测可用率，按可用率给候选排序；可用率明显偏低的源只留一条兜底，减少无谓探测。

**速度**

- 抓取阶段重写：优先走 jsDelivr/fastly 备选地址，直连超时再叠镜像前缀；先探一次直连是否可用，不通就整轮跳过直连。并发 6 → 16。
- 探测阶段按**地址去重**（同一地址只测一次，结果回填给所有引用它的频道），每个频道只保留少量候选、只测速最快的一条。
- 新增本地失效记录：`bad_urls.json`（3 天 TTL）与按 `host:port` 统计的 `hosts.json`（近期全失败则整站跳过）。
- 实测：频道 4008、可用 2828 的一轮，整轮从 668 秒降到 **约 5 分钟**（网络状况不同会有差异）；增量更新只复测上次在用的地址。

**界面**

- 控制台整体重做：统计卡片、分组/画质筛选、台标缩略图、首选源域名、暗色模式、吸顶工具栏、固定底栏、`Ctrl+S` 保存 / `Ctrl+F` 搜索 / `Esc` 关弹窗。
- 设置拆成「更新 / 程序 / 数据源」三段，数据源逐个显示绿点红点与抽样可用率。
- 新增「退出」按钮与 `POST /api/quit`。

**托盘**

- 右下角托盘图标 + 右键菜单：打开控制台 / 立即更新 / 打开输出文件夹 / 退出。
- 更新完成、发现新版本时弹气泡提示（可在设置里关掉托盘）。
- `--no-tray` 可禁用

**升级（安全）**

- 升级源改用 `version.json` + `version.json.sig`，客户端内置 Ed25519 公钥**验签后才升级**；下载后再校验 sha256 与字节数。验签不通过一律拒绝，保留旧版本。
- 设置里可关闭"必须验签"，但不推荐。

**其它**

- 图标重绘：保留"红环 + 胶囊 + LIVE"的原设计，透明背景，10 档尺寸（16–256）逐一绘制，修复了旧图标在小尺寸下发糊、深色任务栏发灰的问题。
- 新增 `LIVE_DATA` 环境变量，可把数据目录指到别处（便携/测试用）。
- 支持 `--no-browser` 直接在后台更新（配合一次性模式给计划任务用）。
