台标补齐、去掉错标、白图看得清了（v1.4.1）。

**这一版只做台标，外加把上一版更新慢的问题收拾干净**

上一版（v1.4.0）换了判据，把"台标只认一个来源、宁可空着也不显示错的"这条规则收得太紧，结果你一眼就看出几个问题：CCTV-8 发灰看不清、CCTV-11 只有方块、湖北卫视白得看不见、农林卫视／福建海峡卫视／TVBS 亚洲台干脆没图，黄金翡翠和亚洲剧还共用了一张 myTV 的通用标。这一版逐个修好：

- **接入台标站 `v.999.team`（约 4 万枚）并排第一**，而且自动按简体／繁体两套名字找图 —— `亚洲剧` 只有 `亞洲劇台` 这个名字下才有对得上的图，`黄金翡翠` 只有 `黃金翡翠` 有。两个台现在是各自的专属台标，不再共用。
- **随包离线图库从 142 张补到 217 张**（新增 75 个台的专属台标：CCTV-11 戏曲、卫生健康、东方影视、辽宁影视、农林卫视、福建海峡卫视、湖北卫视、TVBS 亚洲台……）。库更大但更小：按实际显示尺寸重采样，2.06 MB。
- **白图台标不再压成灰色剪影**：改成垫深色底、原色显示。CCTV 全系从"发灰看不清"变成清楚可读。
- **"同一张图挂在好几个不相干的台上"会被拦下**：宁可显示名字方块，也不给你看错台标；能换到专属图的先换。
- 顺带修掉一个会误杀正常台标的判据（所有"透明底白字"台标曾被判成同一张）。

**更新更快**

- 修掉上一版一个真 bug：更新完的后台吞吐复测每次都抛 `TypeError`，等于从没跑过。
- 单地址探测加硬时限，不再出现某个地址卡 131 秒拖住整轮；源清单前几个地址改成并发抢，不再逐个等 8 秒超时；台标联网补图设每轮上限。
- 实测整轮更新 **249 秒 → 103~172 秒**（本机 347 个可用频道）。

**包体**

- **17.7 MB → 11.98 MB**：离线台标库按实际显示尺寸（208×80）重采样，一张不再是无谓的 300×180。

**还剩什么**

- 90 个县级小台（兰溪新闻、嵊州新闻、平湖民生、开化新闻这类）四个图库和台标站都没有，继续显示名字方块 —— 这是图源本身没有，不是判据问题。
- 个别频道某一轮测不出分辨率，会如实写"未测分辨率"，下一轮通常会补上。
