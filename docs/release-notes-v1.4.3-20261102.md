> `%LOCALAPPDATA%\LIVE直播源`，不会丢）。装上之后，往后的升级就是自动的。

## 这一批改了什么

- **「正在播出」内置节目单，不用再填地址**：央视官方接口（一次批量取 61 个台、秒级）
  + 一份公开完整节目表（往后 5 天 / 往前 7 天，补卫视的具体剧名）。
  优先级：自定义 XMLTV > 央视官方（具体名）> 公开节目表 > 官方只给的大类词；占位档不用。
  抓取只在后台线程，界面只读内存缓存，首屏不受影响；抓不到显示「—」。
- **那一格拆两行**：第一行时间 + 进度条，第二行节目名独占整列（按用户要求）。
- **源**：关掉 YanG（全量 123 条实测 0 条出画面）；新接 `akiralereal/iptv`（14/14 通）
  与 `best-fan/iptv-sources`（20 条中 14 条通）。全量跑完 676 频道 / 346 可用。
- **台名繁简归一**：繁体台名也能认领节目单。
- **「码率不足」按分辨率分档**：4K=8M / 1080P=2M / 720P=1.2M / 480P=0.6M，
  实测 81 张卡片里挂角标的从 5 张降到 2 张，摘掉的都是误报。
- **台标**：名字带 高清/超清/4K 的会剥掉后缀再找图库，面板 80 张卡片全部有台标。
- **升级通道**：下载地址走公共镜像（直连 GitHub 只有约 35 KB/s，13 MB 包下不完），
  客户端多地址重试 + 分块读；换包改成进程内完成，拉起新进程前清掉 `_PYI*` 环境变量。
  安全口径不变：**Ed25519 验签 → 比 sha256 → 比字节数**，三样全对才换包。
- **修**：一次性配置迁移不再跟着版本号重跑（原来会把你自己勾回来的数据源又关一次）。
