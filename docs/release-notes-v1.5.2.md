# LIVE直播源 v1.5.2

**修「在线升级升完，程序自己没起来」。**

## 这次修的是什么

1.5.1 的换包流程是：下载 → 验签 → 起一个隐藏 PowerShell 等本进程退出 → copy 覆盖 exe → 拉起新版本。
实测两次，**包都换成功了，程序都自己没起来**：一次连进程都没有，一次进程卡在 12 MB 不动、端口也不给，
只能手动再点开。

现在改成**在当前进程内直接换**：

- 新包先写成 `<exe>.new`（这一步失败就什么都不动）；
- 把正在运行的自己改名成 `<exe>.old` —— Windows 允许改运行中的 exe，不用等它退出；
- 把 `.new` 放回原路径；万一放不回去，就把 `.old` 改回来，绝不会把自己搞没；
- 用 `--after-update` 拉起新进程，新进程会先等旧进程把端口放掉（最多 20 秒），再接管控制台；
- 启动时顺手清掉 `.old` / `.new` 残留。

## 其他

- 功能与 1.5.1 相同：内置两档节目单（央视官方 + 公开完整节目表）、关 YanG、新接 akiralereal 与 best-fan、
  台名繁简归一、「码率不足」按分辨率分档、台标候选多试一档。
- 升级通道仍是镜像下载 + 多地址重试；安全口径不变：**Ed25519 验签 → 比 sha256 → 比字节数**，三样全对才换包。

## 升级方式

控制台右上「检查更新」→ 提示 1.5.2 → 点「下载并升级」。装好后**程序会自己重新起来**，
不用再手动点开（这就是这版修的东西）。仍停在 1.4.0/1.4.1/1.4.2 的，需要手动装一次。
