# 参与贡献（LIVE直播源）

谢谢愿意帮忙。这个项目很小，规则也很简单。

## 你可以怎么帮

| 方式 | 说明 |
|---|---|
| 报失效源 | 某源长期抓不到/抓到的东西全失效 → 开 Issue，**贴源地址 + 实测日期 + 大致可用率** |
| 推荐更好的源 | 开 Issue 给地址，最好说明它更新频率、包含哪些频道、是否长期可用 |
| 报 Bug | 贴版本号、系统、复现步骤、日志片段（`%APPDATA%\LIVE直播源\LIVE直播源.log` 最后 30 行） |
| 改代码 | 直接提 PR，见下面的约定 |

## 代码约定

1. **只用 Python 标准库**，不引入第三方依赖（打包体积、可审计性都靠这条守住）。
2. **单文件主程序** `LIVE直播源.py`，另有两个随包模块：`_tray.py`（托盘，ctypes）、`_ed25519.py`（验签）。不要拆成更多文件。
3. **对外文案红线**：文档、注释、界面里不要出现这类措辞（平台会误判，且与本项目定位不符）：
   `绕过` / `翻墙` / `梯子` / `科学上网` / `墙` / `破解` / `屏蔽`。用中性表述：**「不依赖域名解析」「本地线路」「连接失败」「可用性检测」**。
4. **不要提交**：`config.json`、`channels.json`、`*.m3u` 产物、日志、`builds/`、`dist/`、`*.pyc`。
5. **不要提交私钥**；签名私钥只在本机，路径走环境变量（见 [CODE_SIGNING_POLICY.md](CODE_SIGNING_POLICY.md)）。
6. 改动前跑一遍自检：

   ```bash
   python tools/preflight_release.py
   ```

## 提 PR 之前

- [ ] `python -m py_compile LIVE直播源.py _tray.py _ed25519.py` 通过
- [ ] `python LIVE直播源.py --once --no-tray --no-browser`（配合 `LIVE_DATA` 指向临时目录）能跑完一轮
- [ ] 没有新增第三方依赖
- [ ] 文案里没有上面的红线词
- [ ] 界面改动贴一张截图

## 讨论与行为

- 就事论事，不人身攻击；不贴盗版/付费内容的获取渠道。
- 讨论内容涉及版权的，只讨论"链接与检测技术"，不讨论内容本身。
