# 合规声明（LIVE直播源）

> 本项目：LIVE直播源 · 作者：海风（kele551） · 仓库：https://github.com/kele551/LiveIPTV
> 最近更新：2026-10-19

## 1. 这个程序做什么、不做什么

**做**：
- 从一个**用户自己启用**的公开列表地址（m3u / m3u8 文本）里读取条目；
- 把这些条目按频道名合并去重；
- 对每个流地址做**连通性测试**与**短时间拉流测速**（只读几 KB 到 512 KB，用来判断"是否真的能播"以及画质档位）；
- 把结果写成一份本地 M3U 文件，供用户在自己电脑/设备上播放。

**不做**：
- 不提供、不托管、不代理、不转发、不二次分发任何直播流或节目内容；
- 不解析、不下载、不缓存节目正片；不提供任何媒体资源下载功能；
- 不采集、不上传用户数据；没有账号系统、没有统计上报、没有广告；
- 不改系统代理、不改 hosts、不改 DNS，不需要管理员权限（除用户自己在设置里勾选「计划任务 / 开机自启」时，由 Windows 的任务计划程序登记，可随时取消）；
- 不内置任何受版权保护的内容；不含任何第三方字体、音乐、图标素材（图标为作者自行绘制）。

## 2. 内容来源与权利

- 程序内置的源地址全部是**第三方公开发布**的 m3u 列表（各自仓库/站点公开可访问），程序只是读取它们。
- 频道名称、台标图片、节目内容的知识产权归各自权利人所有。台标图片**只在界面里以缩略图形式引用原地址**，不下载、不打包、不再分发。
- 本工具与任何电视台、平台、运营商、内容提供方**没有隶属关系**，也不代表其认可或授权。
- 第三方列表的合法性、稳定性、可用性、画质，本工具**不做任何保证**。用户可以随时在「设置 → 数据源」里关闭任意来源，或把内置源全部关掉、只留自己的列表。
- 内置的默认源地址，均取自下列第三方公开仓库/站点（各自由其作者维护，本项目只读取其公开发布的 m3u 文本）：
  `CCSH/IPTV`、`Guovin/iptv-api`、`ChinaIPTV`、`iptv-org/iptv`、`YanG-1989/m3u`。
  这些项目的内容与授权由各自作者负责，与本项目无关；本项目不复制、不镜像、不再分发它们的节目内容。

## 3. 技术边界（不碰的东西）

以下这几件事本程序**一件都不做**，这是它作为"整理工具"的边界：

- 不解除任何**加密、鉴权、付费墙、DRM** 或其它技术保护措施；
- 不伪造会员身份、不复用他人账号、不绕过任何平台的访问控制；
- 不录制、不转码、不存储、不再分发节目内容；
- 不提供"看某个频道"的定向服务：它不认识频道内容，只认识"这个链接此刻能不能出画面"。

换句话说：**能给的是"这条公开链接现在通不通、码率多少"，而不是"这条链接上的内容你有权看"。** 后者由使用地法律和内容提供方决定。

## 4. 使用边界

- 请遵守使用地法律法规与各内容提供方的服务条款，**仅作个人学习、研究与自用**。
- 程序面向"整理与检测"这一技术用途；不面向任何商业再分发、转售、内容聚合发布。
- 若权利人认为某个来源不宜被本工具整理，请通过仓库 Issues 告知，作者会在下个版本把它从默认列表移除。

## 5. 个人信息

- 本程序**不收集任何个人信息**：没有埋点、没有设备指纹、没有崩溃上报。
- 所有数据（配置、缓存、日志、导出的 m3u）都只落在本机数据目录 `%APPDATA%\LIVE直播源`（可用环境变量 `LIVE_DATA` 改路径），不会上传。
- 日志只记录"哪个源抓了多少条、哪些地址判定失效"，不含个人可识别信息。

## 6. 升级与完整性

- 升级源为 `version.json` + `version.json.sig`，程序内置 Ed25519 公钥，**验签失败一律拒绝升级**（默认开启，可在设置里关闭，但不建议）。
- 下载完成后还会校验 `sha256` 与字节数，三者都对才提示替换。
- 私钥仅作者本机持有，不进入仓库、不进入发行包。

## 7. 安全提示

- 公开列表里可能混入**已失效、被劫持、或返回网页/中转页**的地址。程序会把"返回网页"的地址判为失效，并把反复出问题的域名/地址记入本地黑名单，避免重复访问。
- 但仍建议：**不要把某个来源当成可信内容源**；播放器请使用官方渠道下载；对来源的合法性自行判断。
