# 行为准则（LIVE直播源）

## 我们的约定

这个项目是一个人在业余维护的小工具，欢迎任何人使用、提问、报问题、提改进。参与讨论请遵守：

1. **就事论事**：评价代码、方案、数据，不评价人。
2. **不接受**：人身攻击、歧视性言论、骚扰、刷屏、广告、政治宣传、以及任何形式的盗版/破解内容交流。
3. **不索取也不提供**：付费频道、加密流的观看方法；本项目只做公开列表的整理与可用性检测。
4. **尊重作者的取舍**：不是每个需求都会实现；作者会说明理由，你也可以 fork 自己改。

## 适用范围

适用于本仓库的 Issue、PR、Discussions、以及与本项目相关的公开交流。

## 处理方式

- 违反上述约定的内容会被**删除**，必要时**拉黑**账号。
- 有争议时以维护者判断为准；对判断有异议可以私下沟通，但不要在公共区反复争辩。

## 报告

遇到骚扰或不当内容，请通过仓库 Issues 或安全通道联系维护者，并附上链接与截图。
