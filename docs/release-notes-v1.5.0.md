# LIVE直播源 v1.5.0

**「正在播出」这一列不用再填地址了，顺手把源和画质判据都修了一遍。**

## 节目单：内置，开箱就有（新增）

- 以前"正在播出"要自己去设置里找一个 XMLTV 地址，多数人根本不知道去哪找，等于这功能对多数人不存在。
- 现在内置两档，都自动更新、不用配置：
  - **央视官方**节目单（一次批量取 61 个台，秒级）；
  - 一份**公开完整节目表**（往后 5 天、往前 7 天），主要是补卫视那批具体剧名。
- 优先级钉死：你自己填的 XMLTV > 央视官方（给了具体节目名的）> 公开节目表 > 官方只给的大类词。
  「请欣赏××卫视精彩节目」「敬请期待」这类占位档一律不用。
- 卫视以前只写「电视剧」，现在多数能给出**具体剧名**；格子也按你说的拆成两行——
  第一行时间 + 进度条，第二行节目名独占整列。
- 抓取全在后台线程，界面只读内存缓存，首屏不受影响；抓不到就显示「—」，其它功能照常。
- 本次实测：官方源接上 **40 个台**、公开节目表再补 **38 个台**，共 **78 个台**有在播节目。

## 源：关掉一个死的，接上两条活的

- **YanG·Gather 默认关闭**：全量 123 条实测**一条都出不了画面**（咪咕要签名 URL、ttvb 的代理已 404）。
  老配置升级时会替你关一次，之后你自己勾选照样算数。
- **新接两条**（默认开，都带 CDN 备线）：
  - `akiralereal/iptv` 的 IPTV.m3u —— 抽样 **14/14** 能出画面；
  - `best-fan/iptv-sources` 的 cn_all.m3u8 —— 抽样 20 条里 **14 条**能出画面
    （同批 Guovin 7/20、CCSH 全量 8/20、国内 iptv-org 2/20）。
- 本次全量跑完：**676 个频道 / 346 个可用**（央视 31、卫视 44、香港 24、台湾 30、电影 21、少儿 16、体育 6）。

## 画质：「码率不足」按分辨率分档

- 以前全场只有一条 2 Mbps 的线：720P/1.5 Mbps 这种正常源被误挂角标，4K/3 Mbps 的虚标源反而没人管。
- 现在按档来：**4K 要 8 Mbps、1080P 要 2 Mbps、720P 要 1.2 Mbps、480P 要 0.6 Mbps**，
  界面与后端同一张表，有单测逐档比对。
- 拿 81 张实卡片的量：挂「码率不足」的从 5 张降到 **2 张**，摘掉的 3 张全是误报；
  画质角标文字一张都没变。

## 台标：名字带「高清/超清/4K」的也有图了

- 以前整名去图库找不到就是空；现在会依次试剥掉画质后缀的写法。
- 本次实测：面板 **80 张卡片全部有台标**（含 台视高清 / 民视高清 / 浙江卫视4K），全量解析 256/346。

## 其他

- 台名**繁简归一**：繁体写法（民視、鳳凰…）也能认领到节目单。
- 修掉一处旧毛病：**版本号一涨，就把你自己勾选的数据源又关一次**。现在一次性迁移只对它自己那版生效。
- 升级不丢配置、收藏与缓存（都在 `%LOCALAPPDATA%\LIVE直播源`）。

## 升级方式

- 装了 **1.4.3** 的：控制台右上「检查更新」→ 会提示 1.5.0 → 点「下载并升级」即可，进程会自己换包重启。
- 还停在 **1.4.0 / 1.4.1 / 1.4.2** 的：那几个版本里「下载并升级」按钮是坏的，请手动下载
  `LiveIPTV.exe` 覆盖安装一次，之后往后的升级才是一键。
- 升级源带 Ed25519 签名，客户端验签 + 比 sha256 与字节数，三样对上才换包；对不上就保留旧版不动。
