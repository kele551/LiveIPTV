# 更新日志（LIVE直播源）

版本号规则：`主.次.修订`。次版本号用于一批功能性改进，修订号只给单独的小修。外观类微调不单独占版本号。

## v1.4.0（2026-10-21）

**画质判据：从"按台名猜"改成"解析视频流实测"**

- 新增实测分辨率：解析 TS 分片里的 H.264 / HEVC SPS（`parse_ts_video`）、fMP4 的 `moov/trak`（`parse_mp4_video`）、MPEG-2 序列头（`_mpeg2_seq_size`），得到真实像素宽高；PMT 里找不到视频流时按"包里最多的非音频 PID"兜底（CCTV-3、CCTV-5+ 这类私有封装的台也能读出来）。
- 读流窗口下限 0.35 → 0.8 秒，并新增分段解析（400KB / 900KB / 2MB 三个台阶）、换下一片再找 SPS（`_more_segments`）、`EXT-X-MAP` 初始化段解析；实测覆盖率约 97%。
- 新增实测码率与码率档（`MB_TIERS`）；画质分改成"分辨率档 + 码率达标度"（`_src_quality`），用户口径：**分辨率 ≥1000 像素且码率 ≥2 Mbps 才算清晰**（`CLARITY_HEIGHT` / `CLARITY_MBPS`）。
- 新增 `quality_label`（1080P / 720P / 低码率 / 低分辨率 / 未测分辨率）与 `clear_enough`；列表角标直接显示"分辨率 · 码率档"。
- 慢频道单独复测吞吐（`net_pass`，400 KB/s 门槛 `SMOOTH_KBPS`），避免 64 路并发摊薄带宽把好台误判成"慢"。

**台标**

- 来源统一：只认 m3u-logos（主）、wanglindl/TVlogo、fanmingming 三个库（`LOGO_OK_HOSTS`），其它来源一律丢弃，不再白底/彩底/黑底混排。
- 随包离线图库 `logos_lib/`（316 张 / 10.5 MB），首次打开即有台标，不依赖 GitHub 连通性。
- 新增 PNG 自解码（`_png_pixels`，支持调色板 + tRNS、1/2/4/8/16 位）判断台标配色，透明底白图自动垫深色底（`logo_kind`）。
- 台标别名表（`LOGO_ALIASES`）+ 文件名模糊匹配（`_lib_fuzzy`），补回央视子频道与地方台台标；列表统一 104×40 画框，横版/竖版/宽条都不裁切。

**命名**

- 央视按官方台名显示（`CCTV_OFFICIAL` / `official_cctv_name`）：`CCTV-1 综合`、`CCTV-5+ 体育赛事`、`CCTV-4K 超高清`；原名存 `aka` 供搜索命中；同名合并键补 4K/8K 分支，避免 `CCTV-4K 超高清` 与 8K 撞桶。

**界面**

- 列表行加编码徽标（H.264／HEVC）、画质标签、首选源吞吐 KB/s（>400 绿 / <400 红）与"低码率 / 分辨率低"提醒；悬停显示明细（像素／编码／码率／KB/s／首包 ms／线路数）。
- 筛选新增「达标」「仅看清晰」「网络 400KB/s+」「分辨率档」「码率档」「分辨率低」；排序新增「画质优先」「网络最快优先」。
- 行高 72px，台标独立成列；页脚去掉版本号。

## v1.3.0（2026-10-19）

**数据源（这是本次改动最大的部分）**

- 新增 4 个经实测可用的源：CCSH·平台源、CCSH·全量源、ChinaIPTV·自动更新、Guovin·IPTV-API。
- 默认关闭 4 个实测不可达的源：kelvin、epg.pw 的香港/台湾/澳门三源（本机到 `stream1.freetv.fun` 全部超时，2026-10-19 实测 0/135 可播）。
- 老配置自动升级（`cfg_ver=2`）：只关闭这 4 个，不覆盖用户其它选择，日志里会写明改了哪些。
- 每轮抓取后对每个源**抽样 20 条**实测可用率，按可用率给候选排序；可用率明显偏低的源只留一条兜底，减少无谓探测。

**速度**

- 抓取阶段重写：优先走 jsDelivr/fastly 备选地址，直连超时再叠镜像前缀；先探一次直连是否可用，不通就整轮跳过直连。并发 6 → 16。
- 探测阶段按**地址去重**（同一地址只测一次，结果回填给所有引用它的频道），每个频道只保留少量候选、只测速最快的一条。
- 新增本地失效记录：`bad_urls.json`（3 天 TTL）与按 `host:port` 统计的 `hosts.json`（近期全失败则整站跳过）。
- 实测：频道 4008、可用 2828 的一轮，整轮从 668 秒降到 **约 5 分钟**（网络状况不同会有差异）；增量更新只复测上次在用的地址。

**界面**

- 控制台整体重做：统计卡片、分组/画质筛选、台标缩略图、首选源域名、暗色模式、吸顶工具栏、固定底栏、`Ctrl+S` 保存 / `Ctrl+F` 搜索 / `Esc` 关弹窗。
- 设置拆成「更新 / 程序 / 数据源」三段，数据源逐个显示绿点红点与抽样可用率。
- 新增「退出」按钮与 `POST /api/quit`。

**托盘**

- 右下角托盘图标 + 右键菜单：打开控制台 / 立即更新 / 打开输出文件夹 / 退出。
- 更新完成、发现新版本时弹气泡提示（可在设置里关掉托盘）。
- `--no-tray` 可禁用

**升级（安全）**

- 升级源改用 `version.json` + `version.json.sig`，客户端内置 Ed25519 公钥**验签后才升级**；下载后再校验 sha256 与字节数。验签不通过一律拒绝，保留旧版本。
- 设置里可关闭"必须验签"，但不推荐。

**其它**

- 图标重绘：保留"红环 + 胶囊 + LIVE"的原设计，透明背景，10 档尺寸（16–256）逐一绘制，修复了旧图标在小尺寸下发糊、深色任务栏发灰的问题。
- 新增 `LIVE_DATA` 环境变量，可把数据目录指到别处（便携/测试用）。
- 支持 `--no-browser` 直接在后台更新（配合一次性模式给计划任务用）。
