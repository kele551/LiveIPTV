# LIVE直播源 v1.5.3

**换完包，程序真的会自己起来。**

## 这版修的是

1.5.2 已经换成"进程内换包"了，包也换成功了，但新进程**卡在启动早期**：内存停在 12 MB、
连临时解包目录都没建、日志一个字没有。查下来是环境变量的问题——打包后的进程里
`_PYI_*`（PyInstaller 自己的）被新实例继承了，新实例误以为自己是"已经解包的子进程"，
跳过解包之后就卡住。同样的操作从 `python.exe` 里发起就 0.5 秒起来了，差别只有这一组变量。

现在拉起新进程前会把 `_PYI*` 全部去掉再传。以后升级就是：下载 → 验签 → 比 sha256 → 换包 → **自己重启**。

## ⚠ 一次性的例外

能全自动重启的是**从 v1.5.3 起**的升级。如果你现在装的是 1.5.1 / 1.5.2，
升到 1.5.3 这一次包会换好、但需要你**手动再点开一次**（旧版本里的拉起逻辑本身有问题，
改不了已经装在你机器上的那一份）。之后就不会了。

## 其他

功能与 1.5.1/1.5.2 相同：内置两档节目单（央视官方 + 公开完整节目表）、关 YanG、
新接 akiralereal 与 best-fan、台名繁简归一、「码率不足」按分辨率分档、台标候选多试一档。
升级通道仍是镜像下载 + 多地址重试；安全口径不变：**Ed25519 验签 → 比 sha256 → 比字节数**。
