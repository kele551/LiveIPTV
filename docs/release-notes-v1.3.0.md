首个公开版本（v1.3.0）。

**这是什么**：单文件 exe，双击打开一个本地网页控制台，自动聚合公开的直播源，逐个实测能不能出画面、实测码率，只保留电视台频道，按速度排序后导出 m3u 给播放器用。

**这一版做了什么**
- 数据源：内置 40+ 个公开源，逐源抽样实测可用率；默认只开实测能用的 8 个（CCSH、ChinaIPTV、Guovin、iptv-org 的港澳台/国内、YanG）。
- 只保留电视台：以公开电视台名单做白名单，影视切片、直播间、DJ/相声/助眠之类不会再混进列表。
- 速度：一轮完整检测约 1~2 分钟；列表默认按实测码率降序，导出的 m3u 每个频道只写一条实测最快线路。
- 界面：网页控制台，搜索 / 分组 / 画质筛选 / 全选反选 / 手动勾选后保存；装完记得先点右上角「立即更新」。
- 托盘：右下角图标常驻，空闲是三角、更新中是方块；右键可打开控制台、立即更新、打开保存目录、退出。
- 升级：内置 Ed25519 公钥，升级源被改动一律拒绝。

**说明**：直播源都是第三方公开聚合的，随时可能失效；本程序只做"整理 + 实测"，不存储、不转发任何内容。请遵守各源的使用条款。
