画质判据改成"实测"，台标统一来源（v1.4.0）。

**这一版的核心变化：列表里的"画质"不再是猜的**

以前的画质是按台名／标称分辨率估的——湖南卫视标着 1080P，实际只有 1.4 Mbps；`cctv4k.m3u8` 叫 4K，实测是 1920×1080。这一版改成直接解析视频流本身：

- **实测分辨率**：从 HLS 分片里解 H.264 / HEVC 的 SPS，MPEG-2 解序列头，fMP4 解初始化段，得到真实的像素宽高（含 1080P／720P／576P 这类非整档尺寸）；一轮抽样实测覆盖率约 97%。
- **实测码率**：按分片字节数 ÷ 时长算真实码率，不再用文件大小粗估。
- **判定标准（你给的）**：分辨率 ≥1080P 且码率 ≥2 Mbps 才算清晰；网络 ≥400 KB/s（≈3.2 Mbps）才算不卡。两项都过才标"达标"。
- 只测到一项时不硬判：显示分辨率＋码率档，同时标出缺的那项（"低码率"／"分辨率低"），点开可以看到实际数值。

**网络（流畅度）**

- 慢的频道会单独复测一次吞吐（小并发），避免"64 路并发把带宽摊薄、好台被误判成红字慢"。
- 列表里显示实测下载 KB/s，>400 绿、<400 红；筛选里新增「网络 400KB/s+」「达标（1080P+ 且不卡）」。

**台标**

- 统一只用一套图库（m3u-logos 为主，另两个库兜底），不再混着来；同一批频道风格一致。
- **随包带 316 张离线台标**（10 MB），第一次打开就有图，不用等从 GitHub 拉。
- 透明的白字台标自动垫深色底，央视那批原来"白字压白底看不见"的问题没有了。
- 所有台标进同一个 104×40 画框，横版／竖版／宽条都不裁切、视觉大小一致。

**命名**

- 央视按官方台名显示：`CCTV-1 综合`、`CCTV-5+ 体育赛事`、`CCTV-4K 超高清`、`CCTV-8K 超高清`，同一频道的不同写法会合并成一条。

**其它**

- 列表行加编码徽标（H.264／HEVC）、画质标签（如 `高清 1080P · 8.9M`）、首选源域名与吞吐；鼠标悬停看明细（像素／编码／码率／KB/s／首包 ms／线路数）。
- 排序新增「画质优先（实测分辨率 × 码率）」「网络最快优先（不卡）」。
- 探测阶段读流窗口下限提到 0.8 秒（原来 0.35 秒碰不到关键帧，高码率台读不出分辨率）。
- 页脚去掉版本号。
