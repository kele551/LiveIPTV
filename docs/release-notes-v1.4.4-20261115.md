# LIVE直播源 v1.4.4 发行说明（2026-11-15）

**这一版只修一件事：火绒把本程序报成 `Trojan/JS.Redirector` 的误报。功能与界面和 v1.4.3 完全一致。**

## 报的是什么、为什么是误报

- 程序测源必须真去连公开清单里的每一条地址；公开清单里混了别人塞进去的推广跳转页
  （形如 `kkk.jjjj.jiduo.me/api.php?n=...&id=...&tk=...`）。
- 火绒把"进程访问了被标记的网址"记成 `Trojan/JS.Redirector`，**文件本身没有被改动** ——
  那条告警的「操作结果」写的就是「暂不处理」。
- 程序不下载、不执行那些页面里的任何东西，只是拿不到播放流就被判成坏源。

## 这版做了什么

- **保留原有拦截**：推广域名黑名单（`live.iill.top` / `zby.lskk.top` / `jiduo.me` 及其子域）
  + 302 跳转拦截，探测阶段对这些域名根本不发请求。
- **新增整站拉黑兜底**：实测到某条地址返回的是网页 / 占位跳转页（`返回网页`、`假源`），
  就给该站点记一票；同一站点累计 **2 票** → **整站拉黑 3 天**（落盘 `bad_hosts.json`），
  之后同域任何地址都不再请求。要 2 票是为了不误伤 —— 正常站点上偶尔也会挂一两条烂地址。
- **回归测试**：新增 3.6 节 11 条判据（静态接线、票数落盘、阈值、误伤边界），全套仍全过。

## 怎么升级

- 已装 v1.4.3 的：打开程序点「检查更新」，会看到本版，下载完覆盖安装即可。
- 手动：下 `LiveIPTV.exe` 覆盖旧的（数据在 `%LOCALAPPDATA%\LIVE直播源`，不会丢）。
